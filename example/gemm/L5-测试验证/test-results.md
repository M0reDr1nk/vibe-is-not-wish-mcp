**测量条件更正（2026-11-14 21:40）**：descent-5 首轮测量时，本机有一个**遗留的后台基准进程**
（`/tmp/amx-src` 的 perf 探测，占用 CPU 与 AMX 单元）在运行，导致 AMX 吞吐被压低到
114~279 GFLOPS。此前归因为"热降频"**不准确**——真正原因是后台负载竞争。

终止该进程后在空闲机器上复测 1024³：

| 实现 | 首轮（有后台负载） | 空闲复测 |
|------|------------------:|---------:|
| vinw-delivery (AMX) | 279.2 | **301.6 / 338.1 GFLOPS** |
| vinw-amx | 277.5 | **369.9 / 419.6 GFLOPS** |
| accelerate | 349.1 | 559.4 / 571.4 GFLOPS |

结论不变（gate-delivery 315× ≫ 4×），但绝对性能与归因已按实测更正。
