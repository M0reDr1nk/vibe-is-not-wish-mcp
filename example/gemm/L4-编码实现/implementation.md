### 3. AMX 后端（实验性，`make USE_AMX=1`）

**可行性验证（关键发现）**

| 发现 | 结论 |
|------|------|
| 用户态 AMX 在 M3 + 当前 macOS **可用**（无 SIGILL） | corsix/amx 官方测试套件 10+ 指令全部 OK |
| 单寄存器 `ldx/ldy`（bit62=0）**与 pair load 均可用**（首版结论有误：早期测试把数据装 Y[1] 却用 yoff=0 读 Y[0]） | 本实现选 pair load 减少指令数；代价是奇数 k 尾多读一行 → B 加哨兵行 |
| pair load 要求相邻两个 k/相位步**内存连续** | B 必须块状打包 `[n_tile][k][16]` |
| 首版 `-O3` 崩溃经定位为**整数移位 UB**（`row << 56` 对 int），已修；现 `-O3` 正常 | 已移除 -O2 特例 |

**实现**

- tile = 64(M) × 16(N)，fma32 四相位累积（每相位 16 行）
- A 按 m 块打包 `[k][64]`（每 m 块一次）；B 全局一次块状打包 `[n_tile][k][16]`
- 边角块（M 非 64 倍数 / N 非 16 倍数）用朴素 ikj 补算；奇数 K 尾由哨兵行保证不越界
- 未编译 AMX 时符号存在但返回 `GEMM_EINVAL`，调用方回退

**实测（1024³，单线程 AMX）**

| 实现 | GFLOPS | 相对朴素 ijk |
|------|-------:|------------:|
| naive-ijk | 1.74 | 1× |
| naive-ikj | 17.69 | 10× |
| NEON blocked（8 线程） | 119.25 | 69× |
| **AMX 后端（单线程）** | **866.62** | **499×** |
| Accelerate cblas | 1326 | 762× |

AMX 单线程即达 NEON 8 线程的 7.3 倍、Accelerate 的 65%——验证了「自研 AMX 内核」的技术路径成立。

**诚实披露**：AMX 未文档化、平台锁定（M1–M4）、与 Accelerate 同进程混用需隔离（bench 已分段执行）；生产使用需自行评估风险。

**评审更正**（reviewer16）：pair-load 必需与 -O3 必崩两条结论均已被证伪并更正；R4 扩展性实测 3.22× < 4× 门槛，如实记录 FAIL。
