# VINW Roadmap（延期与未来方向）

本文件收录**已明确但暂不实现**的需求，避免 backlog 与待办混杂。
已实现的需求见 `L1-需求拆解/proposals.md` 与 `.vinw/changelog.md`。

## 延期（deferred）

| 编号 | 需求 | 理由 | 前置条件 | 来源 |
|------|------|------|---------|------|
| R32 | **decision_bias 决策倾向**：用户编写倾向 prompt 文件 / 多维问卷，系统据答案间接判定倾向，供裁定与升级参考 | 用户裁定延期；当前 triage 的 difference/analysis/recommendation 结构已能满足大部分裁定需求 | L2 调研已完成（10 维问卷草案 + 规则映射 + 混合形态推荐，见 L2/synthesis.md descent-16 节） | descent-16 用户提出 |

### R32 调研摘要（供未来实现直接取用）

- **推荐形态**：混合——结构化问卷给基线倾向，自由 prompt 文件补特判
- **10 维问卷草案**：质量属性权衡 / 变更胆量 / 风险偏好 / 兼容性 / 流程严格度 / 验证深度 / 文档比重 / 依赖态度 / 评审参与 / 回退策略
- **推断方法**：v1 规则映射（选项 → 维度取值）；v2 LLM 归纳为「倾向卡」，**仅作参考输入，不自动裁定**
- **挂载点**：`AuditTriage.escalations` 输出时附 `user_bias_hint`
- **风险**：倾向漂移（答完即忘）→ 每次升级回显依据；过度拟合 → 仅重排推荐不锁死选项
